# Scoop bucket for OpenDrop VJ

[OpenDrop VJ](https://github.com/kushiemoon-dev/OpenDrop-VJ) is a native 4-deck Milkdrop VJ instrument built on projectM.

```
scoop bucket add kushiemoon https://github.com/kushiemoon-dev/scoop-bucket
scoop install opendrop-vj
```

The manifest follows the releases of the main repository: `scoop update` picks up a new version once the manifest here is bumped. Run `opendrop-vj` or use the Start menu shortcut.
